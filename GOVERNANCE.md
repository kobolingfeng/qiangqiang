# Governance

QiangQiang is an independent open-source project led by its creator and primary maintainer, [@kobolingfeng](https://github.com/kobolingfeng).

## Decision making

- Routine fixes and documentation improvements are decided through normal issue and pull-request review.
- Public API, architecture, security-boundary, and compatibility changes require maintainer approval.
- Decisions favor a small auditable core, typed APIs, Windows-native behavior, AI-friendly structure, and low distribution overhead.
- When tradeoffs are unclear, proposals should be discussed publicly before implementation.

## Project roles

- **Primary maintainer:** roadmap, architecture, releases, security response, final review, and repository administration.
- **Contributor:** anyone whose issue, documentation, code, testing, or review is accepted.
- **Collaborator:** a consistently trusted contributor who may be invited to triage or review. Access is granted gradually based on sustained work and project need.

## Changes to governance

Governance changes are proposed through pull requests and documented in this file. The current primary maintainer has final responsibility while the project remains single-maintainer led.
