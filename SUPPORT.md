# Support

## Usage and design questions

Use [GitHub Discussions](https://github.com/kobolingfeng/qiangqiang/discussions) for setup help, architecture questions, and ideas for applications built with QiangQiang. Include your Windows version, Bun version, frontend stack, and relevant configuration.

## Bugs

Use the repository's bug report form for reproducible framework defects. A minimal reproduction and complete environment details make issues much easier to resolve.

## Feature requests

Use the feature request form and explain the user problem, proposed API, alternatives, and how the change supports the framework's lightweight or AI-friendly goals.

## Security

Do not report vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

Support is provided by a volunteer maintainer on a best-effort basis. Clear reproductions and focused questions are prioritized.
